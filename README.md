# [2026-06-11] DustEthic - Un standard ouvert pour les micro-dons crypto

> Chaque grain compte.
> Version francophone officielle du projet DustEthic. English summary at the bottom.

## Le projet

DustEthic est une initiative ouverte, non lucrative et expérimentale. Son but n'est ni de collecter des dons ni de posséder une idée, mais de définir un standard ouvert que les portefeuilles crypto peuvent implémenter pour transformer les "dusts" (ces soldes résiduels trop petits pour être déplacés sans que les frais réseau ne les annulent) en dons directs et traçables aux ONG.

## Le problème

Envoyer de très petits montants en crypto n'est souvent pas viable : les frais de réseau (gas) dépassent la valeur envoyée. Ces fractions dorment dans les portefeuilles, inutilisées.

Comprendre le problème en détail : https://dustethic.org/le-probleme/

## L'approche

DustEthic n'est pas une plateforme, c'est un standard ouvert que les portefeuilles et les applications peuvent implémenter directement, sans intermédiaire collecteur et sans commission.

- Gratuit : 0 % de commission, aucun intermédiaire collecteur.
- Ouvert : libre d'implémentation par tout portefeuille ou application.
- Transparent : aucun token, aucune garde de fonds, tout est public.

Le donateur choisit librement une ONG. L'ONG reçoit les dons directement sur ses adresses publiques vérifiées. Le standard décrit les règles techniques et éthiques communes, rien de plus.

## Phase 0 - Transparence radicale

Le projet est en phase de conception, expérimental et bénévole. Tout est public et discuté ouvertement : choix techniques, limites et incertitudes comprises. Aucune promesse de résultat, aucune levée de fonds, aucun produit commercial.

Feuille de route détaillée : https://dustethic.org/feuille-de-route/

## Open standard (EN)

DustEthic is an open, non-profit and experimental initiative. It does not collect donations and does not own an idea: it defines an open standard that crypto wallets can implement to turn unused "dusts" into direct, traceable donations to NGOs.

- Free: 0% commission, no collecting intermediary.
- Open: implementable by any wallet or application.
- Transparent: no token, no custody of funds.

Anyone is free to use, adapt or contribute, as long as the original spirit is preserved: neutrality, transparency and fairness.
