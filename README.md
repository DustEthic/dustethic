# DustEthic — implémentation de référence

Code de référence du standard DustEthic : réunir la poussière crypto par agrégation par actif, sans garde, pour la verser à des ONG.

## Spécification

La spécification vit dans le dépot des docs : https://github.com/DustEthic/docs . Ce dépot-ci contient le code de référence.

## Principe

Agrégation par actif, sans garde. L'utilisateur signe et conserve ses clés. L'accumulation se fait dans des contrats autonomes sans clé d'administration, ou via des opérateurs transparents. Les frais réseau sont pris en charge par délégation native propre à chaque chaine, ou par un mécène.

## Statut

Phase 0. Le code de référence n'est pas encore écrit ni audité. Aucun déploiement mainnet. Ne pas utiliser en production.

## Note réglementaire

Selon la juridiction et la conception du contrat, l'opérateur d'agrégation peut relever de règles applicables aux intermédiaires financiers. À valider par un conseil juridique selon l'implémentation.
