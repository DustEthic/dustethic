# Sécurité DustEthic

Date : 2026-06-13

## Statut

Le dépôt est expérimental. Aucun code publié ici ne doit être utilisé avec des fonds réels sans audit et validation juridique.

## Signaler un sujet de sécurité

Utilise le formulaire du site : <https://dustethic.org/contact.html>

Évite de publier publiquement des détails exploitables avant échange.

## Points de vigilance

- compréhension des signatures par l'utilisateur ;
- limites des autorisations ;
- frais visibles ;
- preuve de lot complète ;
- actifs non standards ;
- rôles d'administration ;
- confusion entre intention et don exécuté.

## Principe

Une interface qui pousse l'utilisateur à accepter sans comprendre est un risque, même si le code fonctionne techniquement.
